03 · OPTIONAL PHYSICAL PATH

Set up real hardware

Only students with the parts need this step. Power the Pi off while wiring.

  1. Gather a Raspberry Pi 5, rated USB-C supply, microSD card with current Raspberry Pi OS, DHT11 or DHT22 sensor, jumper leads, breadboard, and 4.7–10 kΩ resistor for a bare sensor.
  2. Install the OS with Raspberry Pi Imager. Boot and open Terminal. Update packages: sudo apt update && sudo apt full-upgrade -y, then reboot.
  3. Wire power off. Pi physical pin 1 (3.3 V) → VCC; pin 7 (GPIO4/BCM4) → DATA; pin 6 (GND) → GND. For a bare sensor, place the resistor between VCC and DATA. Confirm your module's labeled pins before power on.
  4. Prepare Python. In Terminal run:
    sudo apt install -y python3-venv libgpiod2
python3 -m venv --system-site-packages ~/dht-venv
~/dht-venv/bin/python -m pip install --upgrade pip
~/dht-venv/bin/python -m pip install adafruit-circuitpython-dht
    If your OS release has a different libgpiod package name, check apt search libgpiod and install the available runtime library.
  5. Run the downloaded file from its directory: ~/dht-venv/bin/python dht_reader.py --sensor dht22 (or dht11). Expect lines such as 24.1 C | 52.3 % RH on DHT22. Your actual values will vary.
  6. Record evidence. Note the OS version, sensor model, pin connections, five readings at least 2 seconds apart, any retries, and a photo or sketch of wiring. Disconnect the resistor only after powering off, then compare the outcome.
Troubleshooting and verification
  • No reading: verify physical pin 7 versus BCM GPIO4, 3.3 V, common ground, and sensor pin order.
  • Checksum or timeout: restore the pull-up on a bare sensor, shorten wires, wait 2 seconds, and retry; occasional transient errors are normal.
  • Library import failure: use the virtual environment’s Python path for both install and run. Check ~/dht-venv/bin/python -c "import board, adafruit_dht; print('OK')".
  • GPIO access or hardware incompatibility: verify a current Raspberry Pi OS and current Blinka/DHT packages; consult the linked upstream setup guidance.
  • Benchmark: time 10 attempts at 2-second spacing, report successful/failed counts and temperature/humidity range. Do not treat this browser’s example values as measurements.

04 · STUDENT WORKSHEET

Explain your results

Tasks

  1. Run three good samples for each sensor by adding a DHT11 or DHT22. Compare the display precision and record the simulated temperature/humidity.
  2. Disconnect GND, move DATA to GPIO17, and remove the pull-up one at a time. What diagnosis and trace change?
  3. Set the interval to 0.5 seconds. Explain why the run is rejected.
  4. If you have hardware, follow the optional setup and compare five actual readings with the browser examples.
